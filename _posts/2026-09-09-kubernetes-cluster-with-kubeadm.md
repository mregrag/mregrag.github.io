# Kubernetes from Scratch with kubeadm

## Introduction

Building a Kubernetes cluster from scratch is a great way to understand how Kubernetes works under the hood. Instead of using a managed Kubernetes service or a pre-configured distribution, we will build the cluster ourselves using **kubeadm**.

In this guide, we will set up a Kubernetes cluster consisting of a **control plane** and **worker nodes**. We will configure the required components, networking, and node communication step by step.

The goal of this tutorial is not only to get a Kubernetes cluster running, but also to understand what is happening during the setup and how the different Kubernetes components work together.

By the end of this guide, we will have a fully functional Kubernetes cluster ready to deploy applications.
